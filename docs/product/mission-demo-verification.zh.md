## 浏览器联动验证

使用同源两个Chrome标签页，状态由同一浏览器本地存储共享，未调用正式世界写入接口。

| 操作 | 实际结果 |
| --- | --- |
| 初始牧羊女场景，键盘空格保持约3.2秒，再点击Send | 成功蓄能并发射；个人、集体U/D由4/4到5/5，能量10到9；短时显示峰值与实际值分开 |
| Observe同时打开牧羊女详情 | 自动显示规则110首次报道，Unit-01、Ada、同一事件ID、时间及4→5变化一致 |
| 本人添加备注，切换Unit-02，再刷新 | 备注和报道保留；另一身份仅可查看，编辑入口消失 |
| 加载audio测试场景，样本设0，输入“I can see your book”，完成蓄能发射 | 仅规则30生效；noticed进入book；个人U/D为10/12→11/14，集体12/12→13/14；Observe同步报道 |
| 加载overload场景，一次正常蓄能发射 | 共同一分钟第4次输入触发规则10；状态retreat；集体与操作设备12/12→9/7；低于门槛的Band消失 |
| 手机390×844与默认桌面视口 | 两页可读，窄屏文档宽度与滚动宽度均为390，无横向溢出；默认桌面模拟器双列正常 |
| 浏览器错误日志 | 两页均未观察到error级别日志 |

首次浏览器验收发现蓄能按钮失焦会清除已蓄能状态，导致无法点击发送；已将失焦行为改为仅取消未完成的蓄能计时，完成后的待发射状态保留。修正后重新走通发射与跨标签同步。

## 实际边界

同一浏览器同源多标签联动已验证，跨浏览器、跨手机或真实多人服务器同步未实现。身份为模拟设备，不构成生产账户授权。

画面复用现有参考静帧，信号噪点与清晰度可以变化；角色动作、新机位、完整24小时影片及环境声素材尚未制作，事件用明确标记的状态与报道文字表示。

本地麦克风录制和WebAudio失真回放已实现，但本轮未申请用户麦克风权限、未实录验收。语音内容识别以显式文本转写输入模拟，尚未接入自动转写；浏览器验证使用此模式测试内容条件。

现有/dev路径共享全站layout，可能加载既有认证及统计脚本；本轮模拟引擎、报道与备注均只写本地存储，不写生产服务。正式Worlds页面两个上报流程未在本轮替换，先通过独立Observe原型验证。
