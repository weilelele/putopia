## Media decisions

These proposed photos belong in the briefing dialog. For a physical screen photo, frame the relevant feature on the Console from the operator’s normal position and preserve enough bezel to make the viewpoint clear. Keep the image, source and permissions in the production record. When using an existing world frame as a comparison, caption it as a reference. The companion Feed drafts are text only.

| REC 1 | Archive screen photo if a matching source exists | Tight, slightly off-axis frame. The gauge and the closest mooring post must both be readable so players know what to match. |
| REC 3 | Two archive screen photos if matching views exist | Pair the roof opening and the floor view. A single shot would omit the second identifying feature. |
| REC 7 | Archive screen photo if a matching source exists | Shoot the rail and service door in the same frame, low enough to make their relative positions legible. |

| OBS 1 | Optional reference or screen photo | Show one edge where the white lines disappear. Keep enough ambiguity for the viewer to form a description. |
| OBS 4 | Optional screen photo if a matching source exists | Keep the dark surface and at least one bright point. Include an edge if visible. |
| OBS 8 | Optional screen photo if a matching source exists | Keep the arc and most of the pale field. The missing context is the question, so the image should preserve it. |
