# Observe 被动发现联动 Demo

日期：2026-10-16。入口：`/dev/mission-observe`；世界详情使用同一路由的 `?world=shepherdess` 或 `?world=robot-library`。依据 [玩法权威整理](mission-gameplay-spec.zh.md) 与 [共享开发约定](mission-demo-integration.zh.md)。

## 交付范围

- 独立 Demo，不修改正式 Worlds、WorldFeed、EstablishedWorldDetail、全局布局或数据库。
- 英文 UI，页面首部持续显示 **Simulation Preview**，明确是浏览器本地状态和模拟身份。
- 保留现有 Observe 的“世界列表 → 固定画面 → 世界状态 → 内容历史”结构。以统一 **Discoveries** 取代两类手动上报流程，没有创建报道、上传观测或上报异常的入口。
- 列表按最近报道时间排序，展示当前事件、报道数、最新发现与时间。新状态无预造报道，显示操作下一步。
- 详情展示当前世界事件、真实集体与本机上下行、系统发现历史。报道显示稳定 ID、规则编号、用户、Unit、UTC 时间、触发时事件和本机／集体前后值。
- 报道按发生时间倒序；同一时间戳保留共享 store 已提供的最新优先顺序，不按 ID 字符串推断先后。
- 用户名与初始字母头像为同一个可点击按钮，打开共享 `ArchiveSheet` 中的模拟参与者资料，展示 Unit 与发现统计；不关联真实外部账户。
- 本机身份为当前活动 Demo Unit。本人报道可打开备注编辑器，其他身份只读；跨标签身份变化后编辑权限重新计算。备注编辑器有草稿退出保护，写入后仅在共享状态实际返回相同文本时显示保存成功。
- 只显示当前本机实际下行已解锁的非 Remarks Band。失去接入权限即移除选项；之前的选择只从仍可接入的 Band 中解析，否则退回当前可用的第一个。不会展示锁定 Band 名称、占位符、阈值或入口；历史报道仍保留。
- 模拟器链接在新标签页打开，世界专属链接先选择共享世界；列表详情链接保留实际世界 ID。两个页面导入同一 `useMissionDemo` 和 `worldDefinitions`，Observe 不写 localStorage、不另建 store、不生成规则事件。

## 与 A 的联动

代码只导入 `src/lib/mission-demo/index.ts` 与 `store.ts`，不写 A 所有的目录。使用的 dispatch 动作仅为 `select-world`、`select-device`、`add-note`；不存在 `send-energy` 或创建报道入口。事件来源完全是模拟器调用共享引擎后的结算。

SSR 不访问浏览器存储：服务端页面等待 Next 的 Promise `searchParams`，客户端组件依据共享 hook 的 `ready` 显示恢复态。当前世界详情由 URL 指定，因此切换模拟器世界不会把正在阅读的历史详情突然换成另一个世界；其中数值、设备身份、报道和备注仍实时跟随共享状态。

共享状态层负责版本化存储、刷新恢复、Web Locks 串行写入和同源跨标签广播。若其明确报告存储不可用、快照无效或缺少 Web Locks，Observe 显示原因和恢复说明，不把故障伪装成零报道。演示身份不是生产鉴权。

## 父任务浏览器验收步骤

1. 同源打开 Observe 与 Simulator 两个标签页。重置模拟器后 Observe 应展示无报道空态，所有世界计数为 0。
2. 在模拟器选择可接入 Band 并发射能量。Observe 的对应世界计数与最新事件自动更新；进入详情，对比两页报道 ID、用户、Unit、时间、世界与前后值。
3. 在 Observe 给该 Unit 的报道加备注，等待“Note saved.”；刷新 Observe 与模拟器，检查 ID 与备注仍一致。
4. 切换到另一个 Unit，原报道不再出现备注编辑入口。若另一个标签页切换身份时编辑器正在打开，应立即变为其他身份只读视图。共享引擎再次校验归属。
5. 在模拟器推进解锁后，详情接入选项出现相应 Band；集体下降导致该 Band 丢失时，选项立即消失，当前画面退回仍可接入的 Band，不保留锁定入口或名称。
6. 重复触发固定规则：数值可改变，已有规则报道不重复；历史按时间最新优先。世界无报道与未知世界 ID 均有明确空态／返回路径。
7. 先验收 390×844，再检查 320px、桌面、200% 文字、键盘 Tab／Esc、备注草稿退出、输入时保存按钮和关闭控件可达。检查列表长标题与长 ID 不产生横向滚动。
8. 检查参与者初始字母头像、用户名均可打开居中资料 Dialog，无真实账户链接。

## 诚实限制

- 使用已有世界静态图，明确标记为参考固定画面。清晰度显示的是规则计算值，但本页未实现真实画面噪声处理、动态角色、物理变化视频或白噪音；当前事件变化由文案和历史数值表达。
- 历史只有每规则首次成功的系统报道，不把固定规则每次重复数值变化伪装为新的报道。
- 无讨论编辑器；无真实设备、生产账号、公开社交资料、数据库和服务端权限验证。
- 本机存储与跨标签同步的有效范围是同一浏览器配置、同一源。清除站点数据会清除模拟历史；不声称跨设备同步。
- 具体世界参数、测试场景、恢复间隔与概率约定由共享模拟器定义，不把演示配置说成正式世界定稿规则。
