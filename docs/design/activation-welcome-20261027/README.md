## 已确认视觉

- 沿用手机优先的深蓝底、Courier Prime、橙色主动作、BACK TO DASHBOARD 次动作；仅主按钮保留一个右上切角。
- 上方 Console、下方欢迎信与徽章、Antenna 概念图、第四次密封投递，共四块照片。左下边界由 46.5% 向右移动 30% 至 60.45%；右侧空间按同一比例压缩，保留斜切。
- Console 画面局部放大 6%；欢迎信／徽章保留近景；Antenna 和密封信封使用扩景图片，后者缩小更明显。原始公开素材不被替换。
- 下排缩短并接上 Console，不出现缩图后的黑色空条。照片宽高比保留，裁切边界同时作用于 HTML 回退和 Canvas。
- 单一柔边聚光灯依次移动：Console 停留 4 秒，其他各 1.82 秒；每次移动 1.1 秒，总周期 13.86 秒。光圈半径按画面宽度的 46%、30%、22%、20% 平滑过渡，保留轻微呼吸变化。
- 这是用户明确要求的局部影像动效例外：柔边光只作用于照片，不扩散至 UI。无 Pause 控件；离屏／隐藏页暂停，系统减少动态时静态显示，卸载时清理监听与动画。
- 不显示旧图片说明、VOYAGER INITIATION 额外小标题或 “An invitation to the unknown.”。标题、说明和两个按钮始终可读。

## 导航合同

用户确认的去向是首次进入 Initiation 的 onboarding 简报，不是一个名为 `/initiation/new` 的新产品页。整张图片与主按钮都使用现有 `/voyager-initiation?briefing=1`，即使该浏览器已看过简报也可重新打开；简报自身保留已付款用户等既有资格判断。次按钮为 `/console`。

`/register/complete` 是注册任务的完成页：无 ownerTab，不显示全局导航，退出兜底 Dashboard。`/dev/activation-welcome` 仅用于开发与分支预览的无数据写入视觉夹具；正式生产返回 404。
