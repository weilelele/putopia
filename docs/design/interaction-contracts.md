## 1. 页头模式与路由层级

一级由五个主 Tab 的指定入口定义，不按 URL 的斜杠数量判断。例如 `/worlds/live` 是一级，而 `/logs` 是二级。内页签切换不自动升降页面层级。

| 页面模式 | 路由或场景 | Logo | 默认全局导航 | 直接打开时的返回兜底 |
| --- | --- | --- | --- | --- |
| 一级入口 | `/console`、`/intel`、`/devices`、`/worlds/live`、`/voyagers` | 内容页顶部无品牌区；桌面/横屏共享侧栏保留原品牌 | 手机底栏 / 宽屏 Sidebar | 无返回按钮 |
| 二级浏览 | `/logs`、`/profile`、`/voyager-path` | 无 | 保留，归 Voyagers | `/voyagers` |
| 日志正文 | `/logs/[id]` | 无 | 保留，归 Voyagers | `/logs` |
| 情报正文 | `/intel/[id]` | 无 | 保留，归 Intel | `/intel` |
| 设备浏览 | `/devices/live`、`/devices/my-consoles`、`/devices/[id]`、`/devices/batches/[slug]` | 无 | 保留，归 Devices | `/devices` |
| 批次讨论 | `/devices/batches/[slug]/discussion` | 无 | 保留，输入键盘出现时暂时收起 | 当前批次详情 |
| 世界档案 / 正文 | `/worlds`、`/worlds/[id]` | 无 | 保留，归 Worlds | 档案回 `/worlds/live`；正文回 `/worlds` |
| 专注任务 | `/vote`、`/signal`、`/worlds/submit`、`/devices/claim` 及其步骤/结果 | 无 | 隐藏底栏及五项 Sidebar，保留任务退出路径 | 分别为 `/intel`、`/worlds/live`、`/worlds`、`/devices` |
| 资料编辑模式 | `/profile` 内进入编辑；不要求新建路径 | 无 | 编辑期间隐藏，结束恢复 | 回资料浏览态，再按来源返回 |
| 登录 | `/login` | 无 | 保留手机底栏 / 宽屏 Sidebar；键盘展开时按共享规则收起底栏 | 返回实际应用来源；无来源回 Dashboard；登录成功仍继续原任务 |
| 认证 / 独立获客 | register、apply、quiz、activate、new、voyager-pack 等 | 入口按识别需要可选；后续步骤无 | 不强加五项导航 | 合法原任务；缺失时使用对应流程配置的出口 |
| Studio / Worldflow | 独立工作台 | 不重复品牌 | 使用工作区工具；五项导航不占工作区 | 合法来源；无来源回 `/voyagers` |
| Admin / newsletter / 公共介绍 | 独立页面壳 | 品牌展示场景可选 | Admin 用 AdminNav；其余不强加五项导航 | 保留各自真实业务出口 |
| Sheet / Dialog | 任意页面上打开 | 弹层无；背景沿用原页 | 背景导航不可交互 | 关闭返回触发页与触发点 |

`/devices/live` 等别名若实际重定向到一级入口，按最终呈现的页面模式处理，不在重定向前闪现另一个页头。未知新路由必须登记 mode、ownerTab、fallbackHref、navigationPolicy，不能仅靠路径前缀猜测。此处是目标配置合同，不是已经存在的 API。

## 2. 返回、切换与恢复

**导航高亮回答“内容属于哪里”，返回回答“我从哪里来”。** 二者独立计算。返回标签必须描述实际目的地，不能标 Back to Voyagers 却跳到 Dashboard。

| 触发 | 统一行为 |
| --- | --- |
| 从 Dashboard 打开一篇 Log | Voyagers 高亮；页内返回显示 Back to Dashboard，恢复 Dashboard 的滚动位置 |
| 从 Logs 列表打开正文 | 返回 Logs，恢复搜索、筛选、已加载页数和位置 |
| 外部深链直接打开 Log | 无可信应用来源，返回 Logs；不把用户带到浏览器上一站 |
| 点击另一个主 Tab | 打开该 Tab 一级入口；恢复本次会话该一级页的筛选、内页签和滚动，不跳进上一次未完成任务 |
| 点击当前 Tab，当前在其二级页 | 返回该 Tab 一级入口；有未保存输入先走退出保护 |
| 重复点击当前 Tab，已在一级页 | 保持当前内容和位置；不隐式刷新、清筛选或滚到顶部 |
| 登录后继续 | 恢复同源、允许访问的原任务和安全草稿；重新验证权限，不静默提交；无合法目标回 Dashboard |
| 浏览器/系统返回 | 保持真实历史语义；App 内任务退出采用同一草稿保护，不额外生成重复历史记录 |

来源记录只接受同源的实际应用路径及允许的查询参数，不将密码、邀请码、表单正文放入 URL；不能仅凭 history.length 判定安全来源。跨 Tab 高亮不应产生新的导航跳转。

列表恢复按路由 + 查询条件保存稳定记录 ID、相对位置和已加载范围；返回时先恢复数据再恢复位置。记录已删除时回到最近可用位置并简短提示。普通路由切换将焦点送到新页 main/h1；返回列表优先恢复原入口焦点且不引发第二次滚动。刷新丢失会话状态时正常显示可用列表，不伪装已恢复。

## 3. 底栏、键盘与覆盖层

浏览模式保留全局导航；专注任务隐藏全局导航。≥768px 用 Sidebar 的切换规则只适用于需要全局导航的模式，不能让宽屏任务页重新出现五项导航。手机横屏与低高度窗口仍应保持任务及退出可达，不只检查宽度。

| 状态 | 可见区域与补白 |
| --- | --- |
| 浏览，无键盘 | 底栏内容高 72px + 安全区；正文尾部为实际底栏高 + 24px |
| 浏览，有必要固定操作条 | 操作条位于底栏之上；正文补白为两者实际总高 + 24px；两个区域不重复主动作 |
| 输入键盘展开 | 暂时收起底栏及其补白；输入/发送区在可视视口内，避免键盘与底栏叠加 |
| 专注任务 | 无底栏补白；有固定操作条则只计其实际高度、必要安全区与 24px |
| 模态打开 | 背景滚动锁定且不可交互；页面底栏/操作条不得浮到遮罩上；只保留模态自身操作 |
| 键盘或模态关闭 | 恢复原模式、实际高度与位置；不重复叠加 Web 和原生安全区 |

键盘不能只靠输入获得焦点推断：硬件键盘时未必压缩视口。优先使用当前平台可用的可视视口/原生键盘信息；能力不足时使用可滚动正文与随正文输入区作为降级，不能固定出一个遮挡按钮的区域。

共享层级实施默认值：内容 0、必要吸顶标题 10、固定操作条 20、底栏 30、Popover 40、模态遮罩 50、模态 60、模态内辅助浮层 70。Toast 默认层 40；模态打开时相关反馈放到模态内部，背景 Toast 暂缓，不能穿透模态制造不可达按钮。数值集中管理，不在各页任意增加 z-index；原生 dialog 顶层也必须遵循同样的交互先后关系。

## 4. 独立页面、Sheet 与 Dialog 的选择

| 需求 | 默认承载方式 |
| --- | --- |
| 单一短决策、少量字段、完成后立即回原处 | 手机 Sheet，宽屏 Dialog；共享数据与状态 |
| 多步骤、长文编辑、复杂附件管理、需要独立地址/恢复入口 | 独立任务页面 |
| 对象明确的删除/放弃更改确认 | 短 Dialog，展示具体对象与后果 |
| 只读短解释 | 页内说明或 Popover；关键信息常驻 |

Dream 的简短描述与少量材料可以进入 Sheet；增加多步骤或复杂编辑时迁到独立页并保留草稿，不把长表单硬塞进 90% 高度的容器。不要为相同任务维护两份验证和提交逻辑。跨断点切换承载方式时保留输入、状态与焦点。

### 4.1 关闭与退出决策

| 当前状态 | 关闭 / 返回 / Esc / 点击遮罩 |
| --- | --- |
| 未修改或只读 | 可直接关闭；恢复触发点与背景位置 |
| 已修改，未提交 | 所有退出入口走同一保护；提供继续编辑、明确放弃，以及实际支持的保存草稿；不显示没有实现的保存动作 |
| 上传中 | 告知退出会停止当前上传；确认后可中止本地请求，保留已成功项引用和文字；不宣称已删除远端文件 |
| 提交中 | 提示请求仍在处理，关闭不等于取消；可以继续等待，或在可恢复结果的前提下离开查看记录；不无期限困住用户 |
| 结果未知 | 显示正在核对及查询/记录入口；保留请求标识，不回到可重复提交的空表单 |
| 明确成功 | 展示结果后关闭/继续，返回原场景并更新相关内容 |
| 明确失败 | 保留输入与错误；再次退出仍按未保存策略处理 |

有表单或进行中任务的 Sheet 默认关闭下滑手势；只读 Sheet 可启用，且有同等可点的关闭按钮。遮罩点击和 Esc 不绕过保护。需要放弃确认时保留原表单实例；确认层独占焦点，取消确认后焦点回原关闭入口。浏览器离站只能使用平台允许的原生提示，不能保证拦截强制退出；草稿恢复不能依赖该提示。

## 5. 草稿的保存与恢复

草稿按用户/访客会话 + 任务类型 + 对象 ID + 数据结构版本隔离，防止把世界 A 的输入恢复到世界 B。基本文字、选项、已完成附件引用适用；密码、支付信息、认证凭据、原始本地文件不持久化到普通浏览器存储。

| 场景 | 实施默认值 |
| --- | --- |
| 内页签、模态开合、应用内返回 | 保留当前会话草稿；发生关闭保护时先明确保存/放弃结果 |
| 刷新后恢复 | 非敏感文字/选择使用会话范围存储，默认最后修改后 24 小时失效；关闭会话后不承诺仍保留 |
| 跨设备或跨会话长期草稿 | 只在真实服务端草稿能力支持时提供；显示保存时间及失败，不虚构自动保存 |
| 再次进入同一任务 | 提示发现草稿，提供恢复/丢弃，不静默覆盖更新的服务端内容 |
| 本地文件失效 | 保留文件名提示重新选择，不把文件名当成可提交附件 |
| 提交成功 / 明确放弃 | 清除该任务草稿；结果未知时保留到核对完成或明确处理 |
| 退出账户 / 切换账户 | 清除该账户本地草稿及缓存引用；另一账户不得恢复；服务端草稿按原有权限保留 |
| 存储不可用 / 已满 | 保留当前内存输入，说明离开后无法恢复；不显示“已保存” |

24 小时是尚待实现的默认保留时限，可由真实任务的保密性和失效条件收紧；例外必须登记。保存状态只在写入成功后显示。登录可移交当前访客任务的安全草稿，需用户确认恢复，不能扫描合并另一身份的草稿。

## 6. 连续状态与结果确认

### 6.1 通用提交

| 状态 / 触发 | 下一状态与 UI | 允许的动作 |
| --- | --- | --- |
| 编辑 → 提交 | 先本地验证；不合法则原位错误，合法进入提交中 | 修正字段；一次有效提交 |
| 提交中 → 服务端明确成功 | 成功，显示实际结果/记录；清理对应草稿 | 查看结果、下一步 |
| 提交中 → 服务端明确拒绝 | 失败，保留输入，显示可处理原因 | 修正、符合条件时重试 |
| 提交中 → 超时/断网/响应丢失 | 结果未知，不能断言失败；保留请求/操作标识 | 查询状态、查看记录、继续等待 |
| 结果未知 → 查到成功 | 成功，避免再次提交 | 查看结果 |
| 结果未知 → 服务端确认未创建且可重试 | 恢复可重试状态 | 用既有幂等机制安全重试 |
| 结果未知 → 无核对能力 | 明确暂时无法确认；保留信息与真实帮助路径 | 查看现有记录/联系支持；不自动重放写请求 |

点击防重不等于服务端幂等。UI 接入已有操作 ID、查询和幂等接口；若缺少接口，在迁移台账登记依赖，不能凭 UI 动画或计时假造确认能力。关闭页面、中止 fetch 不等于取消已被服务端接受的业务操作。结果未知可在本次任务中保留至解决，不能因草稿时限到期把它改成“未提交”；再次进入应查询真实记录。

### 6.2 上传、投票与队列

| 模式 | 状态与必要转换 |
| --- | --- |
| 上传 | 已选择 → 校验 → 上传中 → 上传成功/明确失败/结果未知；每个文件独立状态，批量中一个失败不重传其他成功项。可中止传输不等于删除附件；清理遵循后端契约 |
| 投票 | 未选择 → 已选择 → 提交中 → 已提交/失败/结果未知；已提交不等于投票结束；是否可改票、能否看结果来自业务权限 |
| 实时队列 | 待提交 → 已排队 → 等待用户选择/处理中 → 成功/失败/取消；仅呈现服务端允许的转换，不要求所有业务经过同一阶段 |
| 实时连接 | 连接中/已连接/重连中/离线与业务队列状态分开；断线保留最后确认状态与更新时间，不把离线改成任务失败 |

无确定上传总量或队列 ETA 时不用假百分比和倒计时。重连先读取最新快照并去重，不重复插入记录、发送投票或自动重提 Dream。

## 启动入口：翻牌子动画

- Web `/`、PWA 启动入口使用 `/welcome`；iOS 使用打包在 App 内的独立启动界面，断网也能播放。
- 使用现有文字 Logo 切片与翻牌效果，不修改图形、字形、主配色。
- 点击任意位置立即进入 Dashboard；未点击则在动画完整播放结束后再停留 3 秒进入。点击与计时器只执行一次跳转，计时器随卸载清理。
- Web 使用 replace，返回操作不重新进入启动页。Tab 切换、详情返回与重新联网不重播。
- 尊重减少动态效果设置：显示原始静态文字 Logo，静态 Logo 显示就绪后停留 3 秒，点击仍立即进入。
- 深链接、通知链接、认证回调直接保留其目标；启动动画不是全局路由拦截器。
- 3 秒是动画播放结束后的额外停留时长，不包含资源加载和动画播放时间，不保证网络数据在 3 秒内加载完成。联网加载与离线默认 Dashboard 继续采用各自的真实状态。

### 启动动画展示与自动进入

翻牌字标下方始终显示原始图形 Logo（48px 宽、原始比例），翻牌期间与完成后均保留。字标在手机端使用可用宽度的 82%，上限 520px；图形 Logo 与字标间距 24px，不再以 88px 图形与接近满宽字标组合。网页需等待最后的字母锁定和展开阶段全部结束，再完整停留 3 秒进入 Dashboard；原生需等待所有字母锁定完成，再停留 3 秒。点击任意处可立即跳过。减少动态效果模式显示静态字标后停留 3 秒，不播放翻牌。单个字母的位置过渡事件不能提前触发完成。

## 一级 Tab 切换加载态

点击五个一级 Tab 后立即高亮目标 Tab，底栏或侧栏保持可用。数据首屏尚未准备完成时，使用同一套内容结构骨架：一级紧凑品牌区、`RETRIEVING ARCHIVE` 状态、三段导航或数字占位、主内容媒体与文字占位、三条列表占位。骨架尺寸贴近目标页面，使用静态深蓝表面与细分隔线；不显示空白页、扫光、虚构百分比或重复 Tab 名称。Dashboard 与 Voyagers 使用数字型骨架，Devices 与 Worlds 使用媒体型骨架，Intel 使用集合型骨架。已有缓存时保留真实内容并在后台更新，不重新遮盖页面。
