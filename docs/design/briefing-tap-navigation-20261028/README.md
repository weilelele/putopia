## 交互与样式

- 全屏左、中、右点按均向前，桌面故事栏外的空白也接受点按；左上返回、左右滑动和方向键保留。底部提示是无背景的文字按钮，支持 Tab、Enter、Space，触控高度 44px。
- Courier Prime / `--fs-caption`（12px）/ `--color-star`，无新背景、边框或装饰。提示单独占底部 74px 与安全区，页面内容独立滚动，避免短视口时覆盖包裹选择。
- 成员资料弹窗、包裹切换、声音、Skip、关闭与套餐选择保留原响应；拖动、选字与嵌套弹窗事件不触发背景翻页。
- `initiation_brief_tapped` 扩展到所有页，保留位置、目标类别、忽略原因和关联编号，`coordinate_space=dialog` 标明坐标按全屏 dialog 归一化。所有 briefing 事件增加 `navigation_mode=tap_anywhere`，区分旧操作方式；页面内容及存储版本仍为 v2，不强制已看过的用户重新看导览。
- 请求与 React 提交成功仍通过同一 `navigation_id` 关联；成功指目标页渲染提交，不表示媒体加载或用户读完。
