# Voyager Feed 实机验收（约 5 分钟）

开始条件：隔离 Supabase 联调通过，预览部署已绑定该隔离项目。由开发者提供 HTTPS 预览地址及测试账号；不要使用生产账号进行写入测试。localhost 地址只指向手机自身，不能直接用于此验收。

请记录手机型号、系统版本及浏览器。优先使用日常手机，iPhone 用 Safari，Android 用 Chrome。

1. **游客入口**：未登录打开 Feed。应只看到紧凑说明、REQUEST ACCESS 和 LOG IN，没有帖子文字、图片或数量。
2. **发帖与键盘**：登录 Voyager 测试账号，点击 Share an update，输入几行文字并选一张测试照片。键盘打开时正文可编辑，底部提交按钮可滚动到并点击，没有被键盘或系统手势区挡住。
3. **草稿**：保存草稿并关闭，刷新页面，再恢复。文字保持；本地照片需要重选，重选前不能发布。
4. **详情与回复**：发布后进入帖子，输入并发送回复，再返回 Feed。返回位置合理；回复输入、计数和菜单均可点击。
5. **断网恢复**：先输入正文，再开启飞行模式，尝试提交。应显示失败/离线提示并保留正文。联网后按页面提示确认结果或重试；不要反复连点，列表最终只出现一条。
6. **Applicant**：换 Applicant 测试账号。能点赞和回复；发帖弹窗说明需要成为 Voyager，按钮为 Voyager Initiation；只能编辑删除自己的回复。
7. **安全区与窄屏**：竖屏下滚动到页面底部，确认浮动按钮不被系统底栏遮挡。尝试放大系统文字；关闭弹窗后页面可以继续滚动。

回报格式：`机型 / 系统 / 浏览器；1–7 全部通过`。如有问题，请给出步骤编号、具体表现，以及截图或简短录屏。不要在截图中显示测试密码。
