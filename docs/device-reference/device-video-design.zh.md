# Multiverse Console 废土世界操作视频设计

更新日期：2026-10-21。制作目标：以阴郁、神秘、照片级真实的废土平行世界，完整呈现左旋钮调频、独立观察、长按蓄能和世界强反馈。本文是本系列宣传视频的制作描述；设备基础操作仍以[设备操作说明](console-operations.zh.md)为准。

## 用户确认的创作要求

- 世界图像更偏废土和阴郁，先制作多个独立世界参考方向。
- 补全左旋钮从电子雪花中逐渐找到世界的调频过程。
- 未触碰顶部按钮时，圆屏里的世界已经持续自然运动，不是静止照片，也不等到互动才开始动。
- 长按蓄能完成并发射后，世界出现明显更大的动作：大风、闪光或信号干扰；每条优先突出一种主反馈。
- 沿用设备、自然成年手比例和操作范式，右旋钮不操作。尽量保持机身、侧屏、手部动作及蓄能环稳定。

以下具体场景、秒数与效果强度是本次制作安排，不新增产品操作或固件规则。

## 画面与镜头

**平行世界运作的核心原则（用户确认，2026-10-22）：所有圆屏中的平行世界均以世界内部固定摄像机的画面呈现。** 整段观察、蓄能和反馈中，内部摄像机的位置、朝向和焦距保持不变；禁止平移、摇移、俯仰、绕行、推拉、变焦、手持晃动、漂移或切换观察点。环境和其中的物体可以自然活动，大风、闪光等反馈也不使内部机位移动。设备外部宣传镜头是另一台相机，验收时应以圆屏为参照比较屏内地标，不能把外部拍摄设备的运动误判为屏内摄像机运动。窗台等支撑线索可帮助建立位置，但不要求每个世界都显示窗框或支撑物；看不见窗台本身不等于违反固定机位原则。

**平行世界内的实体机位（2026-10-22补充，所有世界通用）：** 每个世界都视为有一台相机实际放置在其中。生成前必须先写清具体位置、支撑或固定方式、镜头相对支撑面的高度、朝向以及所处介质（空气、水下或跨水面）。例如放在地面、桌面、窗台或固定在建筑内；按该位置确定透视和遮挡。仅写“固定机位／眼平视角”不够，不能出现仿佛有人站在路中手持相机、无支撑悬空或游走的视点。可用适量地面纹理、窗台边缘或墙体遮挡说明位置，若使用这些线索，应在圆屏裁切后仍可辨认；不强制每张图出现支撑线索，不添加装饰边框，也不要求拍到相机本身。先验收实体机位，再进入付费视频短测。世界自然运动和强反馈围绕该观察点发生，不能无故移动机位。

外部场景延续暗桌面、暖台灯和真实设备质感；内部世界采用低饱和、阴天或暮色、风化材料和有层次的暗部。阴郁不等于欠曝，圆屏里仍要看清主体、材质和运动。

内部观测摄像机始终固定，主体、地平线、道路和建筑位置连续。世界运动来自风、布料、尘埃、水面、雨滴和灯光，不用推拉、摇移、穿行或切镜头代替世界活动。外部镜头优先固定；编辑已有母片时保留其原有运动。

参考图只生成独立世界，不带设备、手、边框、圆形裁边、按钮、进度环或侧屏UI。主要运动区域安排在图像中央约65%范围，供圆屏取景；不把方形素材直接拉伸成圆形。屏内材质、光线和空间应可信，避免游戏概念图、夸张霓虹或过锐的数字贴片感。

## 完整视频时序

以20秒成片为目标；使用母片编辑时以其实际接触动作对齐，不通过改变手部动作强行凑秒数。

| 时间 | 设备与手部 | 圆屏内的世界 |
| --- | --- | --- |
| 0–2秒 | 顶部按钮无人触碰 | 只有运动的电子雪花，不能提前出现清楚世界 |
| 2–7秒 | 手缓慢转左旋钮，Frequency按0.1步进 | 雪花逐渐露出世界碎片、弱信号与轮廓，再锁定同一世界；不能硬切，也不能在旋钮转动前就显现 |
| 7–12秒 | 手离开左旋钮，顶部按钮无人触碰 | 保留至少4秒可辨认的自主运动；每个世界至少有两层自然活动 |
| 12–13秒 | 手自然移向顶部按钮 | 自主运动继续，不提前触发强反馈 |
| 13–16秒 | 同一手指连续按住至少3秒完成蓄能 | 世界继续运动，进度环在前景显示蓄能；不遮成黑屏、不把世界冻结 |
| 16–20秒 | 蓄能后正式发射，手自然退开 | 强反馈明显超过基线运动并持续可辨认的时间；建筑和内部机位保持固定 |

顶部按钮的一次轻触不等于正式发射。松手发射或自动发射的具体机制尚未确定，宣传分镜只呈现已确认的“长按→蓄能→发射”顺序，不补设硬件规则。这里的明显反馈属于所选世界的表现，不代表所有世界必然回应。

## 三个废土世界方向

| 方向 | 独立世界画面 | 未触碰按钮时 | 蓄能完成后的主反馈 |
| --- | --- | --- | --- |
| 灰烬高架 | 废弃工业高架、破损混凝土、锈蚀护栏、灰尘与残破篷布 | 两条松垂布料轻摆；细尘持续缓慢横移 | 大风横扫，尘浪明显加速增厚，布条大幅甩动；桥梁、地平线不移动 |
| 荒漠中继站 | 阴天荒原中的旧接收碟、铁塔与低矮设备房 | 松垂线缆轻摆；薄尘掠过地面 | 远处云层一次短促闪光，照亮地形后恢复暗色；可辅以短暂屏内信号干扰 |
| 淹没城区 | 半淹没的废弃城区、破损通道、锈蚀立柱与暗色积水 | 雨滴涟漪、水流与悬挂塑料片持续运动 | 强阵风吹皱水面，塑料片大幅摆动；或短暂信号撕裂后恢复同一画面 |

三个方向均为创作候选，未分配新的正式Frequency。测试时保留母片已有读数；不能把生成的错误字形登记为产品数值。

## 自然运动与强反馈

- 自然运动要在未接触顶部按钮的连续观察段内清楚可见。不能仅靠后期噪点、画面整体漂移或玻璃反射变化冒充世界活动。
- 强反馈从蓄能完成/发射的同一时刻开始，不能按下第一帧就发生。至少有一项变化在圆屏正常观看尺寸下立即可辨。
- 大风改变尘埃、布条、水面等可动实体，不吹动屏外的手、设备和桌面；不让建筑变形或景别改变。
- 闪光是一次短促的世界内事件，随后恢复基线曝光，不连续频闪，不让屏外场景整片变白。
- 信号干扰只作用于中央圆屏的世界内容，约0.3–0.8秒后恢复可读画面；不是遮挡缺陷的永久雪花。前景蓄能环、蓝色边缘、侧屏和屏外画面尽量不受影响。

## 设备与UI固定项

机身仍以三张结构原图为依据；编辑已有视频时由该母片承载设备外观。右侧UI以OPTIC母版为准。无手转动左旋钮时，左屏亮度、图形和读数保持稳定，顶部按压和世界反馈不引发侧屏闪烁。

正确蓄能设计是细环由大向小单向收缩，持续至少3秒。已认可森林精灵母片里的环实际为扩张，这是待修误差：若任务是“保留母片进行局部编辑”，先保留并如实记录；若制作新交互版本，应落实收缩，不把扩张写成产品规则。本轮新增调频和废土世界制作，不以修复圆环为由改动已有手势。

原片的玻璃反射、屏框遮挡、机身色彩和手指接触关系优先保留；不以重画设备、加按钮或换成另一种屏幕掩盖编辑困难。

## 默认模型与成本控制

先验证低成本短片，再扩展成片。默认从Seedance 2.0开始测试世界风格、自然运动与强反馈；不默认使用Seedance 2.5生成完整20秒。单次先做一个版本，审看结果后再决定是否修改或扩展。

| 目的 | 默认路径 | 需验证的边界 |
| --- | --- | --- |
| 验证世界动效与反馈 | Seedance 2.0，6–10秒、480p或720p、单条；没有声音需求时关闭新音频 | 当前接口为图像/多模态参考生成，没有videoEdit2video，不能承诺保留原片逐帧动作 |
| 验证设备、手和圆环的保留 | 已试用的Kling O3短片原视频编辑，或先报价比较Seedance 2.5的480p样片模式 | 仍需检查圆环是否重绘、文字是否软化；样片成功不代表像素一致 |
| 制作完整20秒 | 短测通过后，再选择同模型分段制作或其他已验证路线 | Seedance 2.0当前输出上限15秒，完整20秒需分段；模型切换和接缝需要再检查 |
| 升级2.5或高清 | 展示真实报价及增加的控制能力，用户确认后执行 | 2.5普通模式不是默认项，不能自动从低成本测试升级 |

短测优先覆盖“未按按钮的自然活动→连续长按至少3秒→明显强反馈”，取约8秒即可验证关键差别；调频可另用短片验证，完整阶段再拼成包含调频的20秒流程。引用视频也只提交必要区间，避免用完整母片测试几秒效果。

每次记录模型、模式、源视频时长、输出时长、分辨率、是否生音、单次报价和实际扣点。Seedance 2.5上传的视频参考时长也计入计价，不能仅按输出秒数估算。未约定预算上限时先展示本条真实报价，确认后生成；已有预算时在预算内推进，超出预算或升级模型另行确认。生成失败或取消是否退点按平台实际回执记录，不假设自动退款。

2026-10-21的首条2.5完整样片报价1610积分，余额4176→2566。用户要求让该条完成并审看，后续按上述低成本流程执行；这次运行不是后续默认配置。

## LibTV制作与验收

1. 独立生成三个废土世界参考图，记录完整提示词与版本。
2. 导入含调频和长按的完整森林精灵母片，不以只有13–18秒的上一轮测试片替代完整流程。
3. 按默认模型与成本控制规则，先预检真实素材、模式、参数、认证与单次报价，制作关键环节短测。短测通过后再扩展完整流程；模型限制不支持时，记录具体限制，使用分段路线并验收接缝，不将参考生成冒充原片编辑。
4. 逐段检查：调频因果；至少4秒不按按钮时的自主运动；至少3秒连续长按；强反馈起点与幅度；世界摄像机固定；机身、手、环、侧屏的稳定性。
5. 原始模型结果与后期版本分别保留，提供完整视频、对照或联系表。抽帧、连续播放与技术解码是不同检查，不互相代替。
6. 记录原生分辨率、实际时长、模型与参数、图像和视频节点、任务、实际费用（如平台返回）、审核问题及文件哈希。工具受理或任务成功不代表全部创作要求通过。
