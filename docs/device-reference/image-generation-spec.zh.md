# 图片模式｜效果图创作路径与生成前确认

## 第一原则：照片级真实感优先

所有设备效果图、独立场景、世界画面与宣传视频原始帧，第一目标都是呈现真实相机拍摄般的视觉可信度，达到以假乱真的观感。真实感是准入条件，优先于氛围、构图、戏剧性、风格和生成速度；有明显渲染感或 AI 痕迹的图片必须返工或替换，不能因“方向可用”进入正式素材库。

真实感不允许牺牲设备原始结构。科幻世界可有虚构内容，但材质、光照、透视与相机表现仍须可信。原始造型图与 UI 母版保留为结构或界面依据，不把工程渲染误称为照片成品。

### 逐图准入检查

1. **材质**：木纹、布纹、纸箱、金属各有真实质感；拒绝平铺重复纹理、鳞片状磨损、塑料感和全表面均匀做旧。
2. **光线**：光源方向、接触阴影、反射、干湿关系及屏幕照明相互一致；不以过暗掩盖缺陷，不用过曝、重调色或光晕制造“高级感”。
3. **几何**：桌板、货架、门窗、箱体与设备的边缘、连接、透视和遮挡成立，无融合、悬空或结构漂移。
4. **相机观感**：景深随距离自然变化，曝光和色彩可信；拒绝局部涂抹、过度锐化、假散景和 HDR 质感。
5. **文字与内容**：不出现伪文字、无意义标识或刻意地点大字；产品屏幕按指定母版核对，不能用模糊掩盖错误。
6. **交付检查**：同时检查整图与原尺寸关键局部，记录实际发现及剩余问题。任何明显问题未解决时标记为“待修／弃用”，从当前可用列表和统一背景中撤下，旧文件仅作历史归档。

“已生成”“比上一版更好”不等于“通过”。通过视觉复查也不声称是真实拍摄或保证任何观察者都无法识别；实际用途需要更大分辨率或更严标准时，应继续复查，必要时改用真实摄影与合成。

图片模式 = 设备造型素材 + 场景素材 + 显示内容素材 + 拍摄与画面设定。每次生成前，先把这四个维度描述清楚，附上对应参考图，形成一张可确认、可复用的模式卡。

**执行规则：先描述并由用户确认图片模式，再开始生成。**未确认的素材或设定应标为“待确认”，不能由生成工具自行补全后直接出图。确认可以在对话中完成，随后将确认的版本记录到文档；已明确确认的内容直接沿用，修改时只确认变化项。

## 三个素材来源与画面设定

| 维度 | 生成前需要明确 | 参考素材及使用边界 |
| --- | --- | --- |
| 设备造型图 | 设备款式、版本、配色、材质、正面与侧背面结构，以及必须保留的细节。 | 指定原始造型图与文件名或链接，按需补充不同角度。原始图作为结构依据；有效生成图仅作辅助，不能覆盖原始结构。已否定的顶部倾角、变形堆叠图不作造型参考。 |
| 场景图 | 放置地点、空间类型、承托物、周边物件、设备与环境的位置关系。 | 指定场景参考图或已确认场景图，例如京都仓库的木工作台、窗边、货架暗角。有待补充的场景素材应先确认；如需先生成场景参考，也先确认场景描述。 |
| 显示内容 | 中央屏幕显示哪个世界、哪一帧、主体是什么；左屏与右屏分别显示什么，哪些屏幕亮起或关闭。 | 指定世界素材文件、Worldflow 素材编号或链接；视频素材同时指定时间点或定帧。侧屏使用确认的 UI 母版。世界参考只决定屏内内容，不能带入其设备造型或背景。 |
| 拍摄与画面设定 | 白天或夜晚、光源方向与强度、明暗和氛围；前后左右视角、俯仰程度、远近与裁切；设备数量、堆叠或遮盖方式；横竖比例、输出张数、单图或拼接。 | 明确本次固定项与变化项。仓库夜景和屏内世界的时间可不同，须分别说明。拼接图需逐格指定视角和内容，保持同一设备及屏幕内容一致。 |

## 从模式确认到有效素材

1. 整理三类参考素材，并填写拍摄与画面设定。明确每张参考图负责哪一部分。
2. 向用户展示模式卡和对应参考图，列出待确认项。用户确认后，记录模式版本，再开始生成。
3. 按已确认模式生成。批量版本先列明每张的变化项；单纯修改中央世界时，锁定设备、场景、侧屏 UI 和构图。
4. 首先通过上述照片级真实感准入检查，再复查造型、顶部倾角、旋钮与边框、屏内主体、侧屏 UI 清晰度及拼接一致性。不达标图片返工或替换，不作为有效参考继续传播。
5. 将有效图、原始参考、模式卡和生成记录存入本地专门文件夹，并同步到飞书对应位置。修正版与旧版区分，保留可追溯记录。

以后沿用某个模式时，直接引用模式编号与版本，并说明本次要改哪些维度。若请求已明确确认变化内容，无需重复询问相同事项；出现新素材或未明确设定时，先补齐并确认，再生成。

## 本批图片的模式示例

**京都仓库 · 夜景暗角 · 机器人图书馆。**设备为当前米白前面板、深色机身、银色边框与橙色细节的款式，结构依据最初三张造型图；场景采用本批已展示的京都仓库木工作台、旧帆布与暗处货架。中央屏幕采用用户指定的机器人废弃图书馆画面，左右屏幕亮起，右屏沿用 OPTIC 母版。

仓库外部为夜晚，保持低照度、冷色轮廓光与神秘感；屏内图书馆为暖金色光线。单图采用左前侧视角，竖版拼接展示主图、背部、右屏和旋钮细节。本次仅替换睡眠精灵世界，保留原有场景设定。此例用于说明已有图片的模式组成，不代表已确认任何新的生成批次。
