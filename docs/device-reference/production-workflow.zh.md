# 宣传图与视频制作流程

## 第一原则：照片级真实感优先

所有生成图片及视频原始帧必须具有真实相机拍摄般的可信度，真实感优先于氛围、风格、构图与速度。明显重复纹理、错误反射、伪文字、结构漂移、涂抹或渲染感均为返工条件；不达标图片必须替换，不能作为正式背景或后续生成依据。逐图执行[照片级真实感准入检查](image-generation-spec.zh.md)。产品结构仍以原图为准，界面仍以指定母版为准。

## 推荐路线

建议采用「固定设备造型 + 独立屏幕内容 + AI 环境与运动」的制作方式。当前四张世界屏幕图适合确认视觉方向；进入正式宣传制作后，机身和屏幕分别制作，能减少改一个世界就重新改变产品外形的问题。

## 1. 先锁定产品素材

- 以本库三张原图为结构依据。向工业设计方取得原始 CAD/三维模型后，导出正面、左右前侧、后侧、略俯视等相机视图，并记录焦距、机位和光照。新角度优先从同一个模型渲染。
- 每个常用机位保存一张黑屏底图、一张亮屏示意、机身透明底、三块屏幕蒙版、玻璃反射层和接触阴影。上述分层素材是下一阶段需制作的交付物，本库目前提供的是合并后的位图。
- 顶部坡度、侧旋钮位置、中央圆屏直径和前下沿是每张图的必查项目。生成图不替代工程模型；不把有误版本继续喂回模型。

## 2. 用 Worldflow 做内容来源

本批从已有 Worldflow 定帧选出四个画面：

| 版本 | 世界 | 镜头 | 圆屏构图重点 |
| --- | --- | --- | --- |
| 01 | 93.2 牧羊女 | 草地 / 早上 / 看书 | 人物、书本与羊；避免直接中心裁切丢失人物 |
| 02 | 92.5 贵州3 机器人与流浪猫 | 废弃图书馆 / 白天 / 机器人看书 | 原画右侧机器人与书本，保留环境光束 |
| 03 | 93.9 贵州 精灵世界 | 睡眠叶 / 清晨 / 晨间睡眠 | 睡眠面部、苔藓与翅膀 |
| 04 | 93.2 牧羊女 | 草地 / 夜晚 / 空镜 | 可读的山坡轮廓与星空，避免过曝 |

建议每次出片关联世界、地点、时段、事件、源素材版本、设备底图版本、圆屏取景位置、输出比例、生成提示词和审核状态。Worldflow 的定帧与对应视频继续作为源资产；衍生成片另存新版本。

状态建议为：草稿 → 结构审核 → 屏幕/UI 审核 → 可用于宣传。此次公开图是参考资产，尚不等同于经过逐像素 UI 审核的宣传定稿。

## 3. 静态图批量生产

1. 先批准一张完整机身与环境底图，再固定该机位。
2. 将源世界图裁成适合圆屏的构图，再做透视匹配和圆形遮罩；玻璃反射层叠在内容上方。
3. 左右仪表单独绘制，固定文字、频率、图标与动画。当前生成图的 115.5 等小字为原参考 UI 的视觉延续，不代表世界频率映射或真实产品规格。
4. 在整张画面中校正屏幕亮度、色温、反射与轻微溢光。保留屏幕边界和厚度，避免变成发光洞口。
5. 更换世界时复用同一个设备底图。AI 主要用于环境、布料、光照与气氛；多机堆叠逐台核对，不把融合和变形当成遮挡。

本次四张使用内置 image_gen 进行多图编辑，并保存了完整提示词。AI 对源画面做了适应性重构，不是无损贴入；因此正式生产建议转成上述可重复的分层合成。

## 4. 视频从短镜头开始

建议先试制一个约 15 秒样片：

| 镜头 | 建议成片长度 | 内容 | 制作方式 |
| --- | --- | --- | --- |
| 01 | 3 秒 | 仓库暗角，布料下露出设备 | 已审核的机身底图，环境微动或轻微推近 |
| 02 | 3 秒 | 旋钮和侧屏亮起 | 产品模型/实拍近景，独立 UI 动画 |
| 03 | 3 秒 | 中屏雪花转为一个世界 | 同一圆屏蒙版内切换视频，不重画整台机器 |
| 04 | 4 秒 | 世界细节缓慢活动 | 复用 Worldflow 对应视频，透视与反射合成 |
| 05 | 2 秒 | 完整设备和品牌收尾 | 锁定机身，后期添加正式品牌文字 |

先让一条镜头只承担一种主要运动，例如轻微推近、微风或光线变化。图生视频输入画面负责设备、构图和光照，提示词集中描述运动；这也符合 [Runway 官方图生视频提示指南](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide) 的方法。

示例运动提示词：`Locked camera. A faint breeze moves the loose edge of the cloth. Dust drifts slowly through the window light. The device rests firmly on the table.`

有摄影机运动时，屏幕视频需要平面跟踪与透视匹配，并保留圆屏蒙版和玻璃反射。可使用 After Effects 的运动跟踪/Corner Pin 工作流；参考 [Adobe 官方跟踪与稳定说明](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/track-motion/tracking-stabilizing-motion-cs5.html)。

大幅环绕、从正面转到背面、复杂揭布、多台设备近景堆叠，对连续几何要求较高，我建议优先用同一三维模型或实拍，AI 用于环境和世界内容。每个视频检查首帧、中间帧、尾帧，再检查整段连续播放，尤其留意顶面呼吸式变形、旋钮移动、屏幕边缘抖动与小字漂移。

## 5. 导出与开发交接

- 同一镜头分别构图输出 16:9 与 9:16；竖版不要依靠最后机械裁切，预留完整设备和标题区域。
- GitHub 保存可公开的精选参考图、提示词、清单和规范；完整高分辨率视频、分层工程和大量候选图保留在专门的媒体存储中，并使用稳定资产标识关联。
- 固定资产版本并记录 SHA-256。更新图片时新建版本，旧版本注明用途或弃用原因，防止开发者误用。
- 推荐先完成「一个批准的设备机位 + 三屏分层模板 + 四个世界视频替换」的小样板，验证一致性后再扩展仓库、暗角、桌面等系列场景。
