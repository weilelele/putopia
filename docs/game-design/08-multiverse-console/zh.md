# 08 · 多元宇宙控制台（Multiverse Console）

## 1. 定位

Multiverse Console 既是**世界观的核心道具**（航行者用来观测平行世界的复古设备），
也是产品**首页对访客的"钩子"**——一个可交互/可展示的控制台面板，用来制造神秘感与"这台设备能干什么"的好奇。
它把抽象的"探索多元宇宙"具象成一台有旋钮、有屏幕、会亮红灯的机器。

## 2. 玩家触点

- **访客首页 Hero**：品牌 wordmark（翻牌动画）+ 设备图标 + 叙事文案（"你闯入了 Multiverse Collective
  的内部网络……最神秘的仪器 Multiverse Console——一台能伸进平行世界去观测的设备"）+ **MC 控制台面板**
  （`McConsolePanel`）+ 申请/登录 CTA。
- **路径状态条**里的"设备"格：航行者尚未被分配 Console 时，点开显示"设备扫描中，准备好会通知你"弹窗。
- **设备档案**（07）里的一台台 Console 实体即此设备。

## 3. MC 功能面板（`mc_functions`）

控制台面板展示一组"功能项"，由 Architect 在后台 `/admin/mc-config` 配置（标题、描述、排序等）。
这是一个**数据驱动的展示组件**——运营可以增删改控制台"能做什么"的清单，用来逐步揭示设备能力、
制造期待，而无需改代码。

| 项 | 说明 |
|---|---|
| `mc_functions` 表 | 功能项：title/description/sort_order 等 |
| 读 | `getMcFunctions`（缓存 5 分钟，全员同一份） |
| 写 | Architect CRUD（`/admin/mc-config`） |

## 4. 设备虚构要点（来自日志与文案）

- 外形像复古收音机/电视/显示器的混合体，有左右旋钮，需拧动搜索信号。
- 屏幕显示平行世界画面，常带不确定性/故障感（呼应 Signal Dispatch 的"故障化"素材处理）。
- **红灯 = 与平行世界建立了连接**；**量子能量按钮 = 向平行世界发送讯息**。
- 每台设备有归属与流转史（见 07 的 Unit 001 等）。

## 5. 当前状态与缺口

- ✅ 首页面板、叙事 Hero、`mc_functions` 数据驱动配置、设备登记均已上线。
- 🟡 控制台目前更偏"展示 + 叙事"，**没有真正的"操作设备产生玩法结果"**的交互（旋钮/红灯是视觉/文案层）。
- ⬜ "拥有一台 Console"对航行者尚无功能性后果（仅身份象征 + 设备档案里的归属）。

## 6. 未来钩子

- 把 Console 做成真正的玩法入口：拧旋钮=进入某个世界的信号辨认（接 Signal Dispatch），
  红灯=成功贡献/连接达成的反馈。
- `mc_functions` 从"展示清单"升级为"可点击的功能入口"，按角色/标签解锁不同能力。
