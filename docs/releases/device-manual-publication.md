# Device 人工发布说明

Batch 基础 Info 和 Updates 按 [Batch 基础信息概述](../product/device-batch-overview.zh.md) 维护。
内容由管理员手动编辑、核对和发布，日期只用于展示，不触发自动发布。

## 操作步骤

1. 进入 `/admin/device-batches`，选择目标 Batch。
2. 在 Overview、Packs、Latest Update 编辑基础介绍、包裹说明和更新，可附图片或视频。
3. 点击 `SAVE DRAFT` 保存草稿；公开页面不会改变。
4. 核对整批修改后点击 `PUBLISH LIVE`，确认后更新公开页面。该操作发布整个 Batch 当前配置，
   包括同时修改的价格、库存和 Pack 信息，并非只发布当前 tab。
5. 在用户页面检查结果。需要通知关注者时，再单独使用 `EMAIL FOLLOWERS`；Pack 通知使用现有独立入口。

Preview 和本地后台可能连接生产数据；发布时按确认框核对目标与影响。
Updates 可以为空，保存和发布都不会自动发送邮件。

## 已移除的旧流程

Story Lab 的导航、页面、AI 生成接口、审核操作、发布记录操作及自动发布接口已从代码库删除。
无需故事适配、两轮内容审核或额外登记，即可通过 Batch 编辑器发布。
旧写作指南、故事蓝本和等待体验文档已删除，内容规范统一到基础概述。

本次没有删除历史数据库记录，也没有改写已有版本化 SQL 迁移。旧表不再被应用代码读取或写入。
付款、订单履约、邮件规则及 Worlds 队列不属于本次移除范围。
